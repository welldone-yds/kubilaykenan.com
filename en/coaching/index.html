    Coaching work

    A plan of their own for every student.

    When I work one-to-one with my YDS, e-YDS and YÖKDİL students at Ankara Dil Akademisi, I don't use a ready-made template. I first measure where they are, turn the target score into a number of correct answers, write a personal plan for the days left, and we check it together every week.

    How I work

    Four steps, in the same order for every student. What changes is the exam date, the level and the hours available each week.

    Measure

    A placement test or the latest practice exam: how many correct in each section, and where time is lost.

    Turn the target into numbers

    How many correct answers the target score means, and which sections they can realistically come from.

    Write the plan

    The days left are split into weeks; each day lists what to study, with the source and page number.

    Check in every week

    What's done, what's left, what was hard; the plan is updated if needed, with a section-by-section analysis after each practice exam.

    A plan is a calendar, not a list.

    Each student's plan is written week by week, day by day, up to the exam date. Sources and page numbers are set, and every finished task gets a tick. The answer to "What do I do tonight?" is always on the page.

    The page shown is an anonymised, simplified sample based on real plans.

    Every plan has the same building blocks; the content depends on the student.
